# Product standards

Product level: the product's taste, in this repo and changed by PR. Read by triage, workers and verifiers at the point of use.

## Always ask

Things that must always come back to the Artisan. Only the Artisan changes this list (setup or a retro lesson).
- Changes to how a craft flies (ascent, transfers, landing, the margins the checks use)
- Changes to the prompt or anything that adds LLM cost per flight
